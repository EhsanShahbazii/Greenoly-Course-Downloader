# ارسال دوره‌های گوگل‌درایو به تلگرام از کولب

این ابزار با حساب کاربری خودت و Telethon کار می‌کند؛ bot token لازم ندارد. فایل‌های درایو حذف یا تغییر نمی‌کنند. فقط دستورهای ارسالی خودت در Saved Messages اجرا می‌شوند. فایل‌ها یکی‌یکی ارسال می‌شوند تا ترتیب حفظ شود.

## ۱. اتصال درایو

در یک سلول Python کولب اجرا کن و اتصال حساب گوگل را تکمیل کن:

```python
from google.colab import drive
drive.mount('/content/drive')
```

## ۲. ترمینال کولب

```sh
cd /content
git clone https://github.com/EhsanShahbazii/Greenoly-Course-Downloader.git
cd Greenoly-Course-Downloader
python -m pip install -r requirements-telegram.txt
python scripts/drive_to_telegram.py
```

مخزن فعلاً خصوصی است؛ clone نیاز به دسترسی گیت‌هاب دارد. اگر git نام کاربری و رمز خواست، نام کاربری گیت‌هاب و Personal Access Token دارای دسترسی خواندن این مخزن را وارد کن؛ رمز معمول حساب کاربرد ندارد. توکن را در URL، سلول ذخیره‌شده یا چت قرار نده. اگر مخزن قبلاً clone شده، به‌جای clone داخل آن `git pull --ff-only` اجرا کن.

`api_id` و `api_hash` حساب تلگرام را از my.telegram.org بگیر. برنامه در ترمینال این دو مقدار، شماره تلفن، کد ورود و در صورت فعال‌بودن رمز دومرحله‌ای را می‌پرسد. api_hash هنگام تایپ نمایش داده نمی‌شود. می‌توانی دو متغیر محیطی `TG_API_ID` و `TG_API_HASH` را هم از قبل تنظیم کنی.

مسیر پیش‌فرض دوره‌ها `/content/drive/MyDrive/GreenOly` است. هر زیرپوشهٔ مستقیم یک دوره محسوب می‌شود. مقصد پیش‌فرض Saved Messages خودت است. برای کانالی که اجازهٔ ارسال در آن داری:

```sh
python scripts/drive_to_telegram.py \
  --root '/content/drive/MyDrive/GreenOly' \
  --target '@YOUR_CHANNEL'
```

برای کانال خصوصی، شناسهٔ عددی مانند `--target=-1001234567890` را بده. حساب باید کانال را بشناسد و اجازهٔ ارسال داشته باشد. مقصد در طول اجرای برنامه ثابت است؛ فرمان‌ها همچنان فقط در Saved Messages پذیرفته می‌شوند.

## ۳. فرمان‌های تلگرام

در Saved Messages حساب واردشده بنویس:

```text
/gr list
/gr 1-12
/gr 3
/gr status
/gr stop
```

ابتدا `/gr list` را ببین تا شمارهٔ درست دوره‌ها مشخص شود. در اجرای اول، ترتیب نام دوره‌ها طبیعی است و شماره‌ها در فایل `courses.json` ثبت می‌شوند. دوره‌های تازه به انتهای فهرست اضافه می‌شوند؛ حذف یک پوشه شمارهٔ دوره‌های دیگر را جابه‌جا نمی‌کند. اجرای دوبارهٔ همان بازه، فایل‌های ثبت‌شده برای همان مقصد را رد می‌کند. برای انتخاب ترتیب دلخواه، وقتی برنامه خاموش است ترتیب نام‌ها را در `courses.json` عوض کن؛ سپس مجدداً `/gr list` بگیر.

ترتیب ویدیوها اول بر اساس شمارهٔ ابتدای نام فایل (`001 - ...`) است، حتی اگر در فصل‌های متفاوت باشند؛ برای فایل‌های بدون شماره از ترتیب طبیعی مسیر استفاده می‌شود. کپشن شامل نام دوره، فصل، نام درس و هشتگ نام دوره است. فاصله‌ها و خط تیره‌های نام دوره در هشتگ به `_` تبدیل می‌شوند.

`/gr stop` بعد از پایان فایل فعلی اثر می‌کند. در خطای ارسال، صف متوقف می‌شود تا ترتیب به هم نخورد. محدودیت موقت تلگرام باعث انتظار به اندازهٔ اعلام‌شده می‌شود؛ محدودیت حساب و اندازهٔ فایل دور زده نمی‌شود. اگر خطای اندازهٔ فایل رخ داد، باید آن را جداگانه حل کنی و بازه را دوباره اجرا کنی.

## ادامه بعد از قطع کولب

وضعیت و سشن ورود در `/content/drive/MyDrive/.telegram-upload` ذخیره می‌شود. این پوشه دسترسی ورود به حساب تلگرام دارد؛ آن را به اشتراک نگذار و وارد گیت نکن. برای مبدأ دیگر، پوشهٔ وضعیت جداگانه با `--state-dir` بده. یک صف همزمان اجرا می‌شود.

بعد از قطع runtime، درایو را دوباره mount کن و برنامه را با همان مسیر و مقصد اجرا کن؛ سپس همان بازه را بفرست. فایل ارسال‌نشده ممکن است از ابتدا آپلود شود. اگر برنامه دقیقاً بعد از ارسال و قبل از ثبت وضعیت قطع شود، احتمال تکرار همان یک ویدیو وجود دارد. تغییر نام، اندازه یا زمان ویرایش فایل هم آن را فایل جدید محسوب می‌کند.

کولب اجرای دائمی را تضمین نمی‌کند؛ خاموش‌شدن runtime برنامه را متوقف می‌کند. `nohup` جلوی پایان runtime را نمی‌گیرد. برای صف دائمی همین برنامه را می‌توان روی سرور با مسیر محلی یا mount درایو اجرا کرد.
